# FlyNote — AI Socratic Learning Platform

FlyNote is a web-based learning platform built around the Socratic method. Instead of giving direct answers, it leads learners through structured, probing questions that push for depth and real understanding.

Live Demo: https://fly-note.singhalabhay.com.np/

---

## Overview

FlyNote breaks complex ideas into conversational reasoning paths. As the user responds, the system reshapes the dialogue, pushing them away from surface-level answers and toward clear, well-formed thinking.

The experience feels closer to having a disciplined mentor than browsing a traditional learning website.

---

## How It Works

FlyNote’s backend is built around a custom reasoning engine that handles:

- Dynamic question routing based on user responses  
- Context persistence and multi-step reasoning flow  
- Difficulty escalation tied to user performance  
- Error-focused feedback that exposes gaps in understanding  

The system doesn’t just store messages. It interprets, reorganizes, and guides them through a structured learning path.

---

## Tech Stack

Frontend: Next.js, React, TailwindCSS  
Backend: Supabase (auth and data), custom reasoning engine written for adaptive learning logic  
Infrastructure: REST endpoints, secure session handling, and multi-context state management  
Deployment: Vercel

---

## Purpose

FlyNote exists for one reason: to teach people to think.  
Not to hand them answers.  
Not to let them coast.  
But to challenge them through disciplined questioning until they arrive at understanding that’s earned, not borrowed.
